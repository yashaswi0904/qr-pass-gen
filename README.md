# Event Ticket & QR Pass Generator 🎫⚡

A web app to generate event tickets and downloadable/scannable QR passes.

## 🚀 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)

## 📁 Project Structure
- `index.html` - Main landing page / generator form
- `pass.html` - Ticket & QR pass display page
- `style.css` - UI layout & styling
- `app.js` - Dynamic logic & QR code generation
